## 复核后的设计修正

工作中曾考虑在所有 FLUSH/RELEASE 周期禁止命令接受。进一步检查发现真正换帧已经被原有 swap_pending 阻挡，正常不换帧的 FIFO 刷新不会改变 Front/Back；全面禁收反而可能吞掉 A 的单周期 START。因此最终实现保留原接收时机，仅增加 fault 禁止，并在 RELEASE 再次检查 fault/owner/error；测试包含正常 flush 期间接收命令的兼容用例。不要把早期讨论中的全面禁收当成最终合同。
