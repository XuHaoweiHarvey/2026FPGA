# LUNARIA 星海梦境视觉预览

更新：2026-10-30。原生画面 640×480，共 16 个场景、128 秒。支持切换场景、暂停/重播、时间轴、拖动玩家光点，以及浏览器 FPS、敌弹和活动元素的当前/峰值。

## 设置

- 电脑参考效果：输入 64–4096 任意整数，点击“应用数量”。
- 板端负载预览：输入 64–512 任意整数，默认 256。
- 数量表示同时存活敌弹上限，不是强制填满屏幕。调整后重建当前场景并清除峰值，容量不足时整批延后。
- “花瓣 / 星形边扩张边旋转”默认关闭；开启时围绕出生中心扩张旋转。
- 玫瑰花瓣支持 3/4/5/6 瓣、轮换和 k=7/3。奇偶瓣分别采样，避免四瓣误变八瓣。
- 设置随对话保存恢复。减少动态效果偏好会暂停播放。

## 场景

环形、六臂螺旋、黄金角向日葵、玫瑰花瓣、五角星、六芒星、加速幕帘、诱导弹、自机狙、反向摩尔纹、多边形、停顿重瞄、独立弧线弹、预警激光、留隙圆环、组合符卡。

普通弹越界回收，16 秒兜底寿命。默认花瓣和星形保存出生方向，后续新批次改变方向；开启扩张旋转后旧图案也转动。玩家射击和命中只展示外观，不计算完整游戏生命与胜负。

浏览器“板端负载预览”控制容量与密度，但不是固件模拟器：时序、编排、精度和绘制与 C 程序有差异。板端将变体组合在八阶段战役，效果可参考 output/lunaria/verification/ 中的 C 渲染输出。浏览器帧率不等于板卡帧率。

## 文件与验证

- lunaria-dream-barrage.html：可编辑片段，生成素材与交互场景。
- lunaria-inspection.html：独立浏览预览，含宿主样式和状态保存适配。
- inspect-lunaria.cjs：Edge / Playwright 检查时间推进、完整图案、数量设置、旋转、状态恢复、预警、停顿、界面与素材一致性。
- preview-checks.json：实际结果和源文件 SHA-256。最近通过 10,914 条断言，覆盖六档板端数量、五档参考数量与 320–820 px 布局。
- assets/：程序生成的背景、Boss、玩家、命中特效、米粒弹和星弹图集。

新星弹素材由 node design/lunaria_preview/inspect-lunaria.cjs --assets-only 导出。scripts/prepare_lunaria_assets.py 将素材重排为板端图集，包含八个米粒弹方向和三种星弹颜色。升级旧星海版时需重新配置原 v10/v11 bit 解除旧素材封存，再加载配套 ELF 和素材。

交付目录 output/lunaria/ 内的 preview.html 可直接浏览。上板步骤、数量口径和实测状态见 docs/LUNARIA_GAME.md。
