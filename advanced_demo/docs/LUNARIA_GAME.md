# LUNARIA / 星海梦境工程版

更新：2026-10-30。已加入实时 FPS、敌弹/活动元素的当前与峰值、64–512 可调敌弹上限，以及反向螺旋、分数玫瑰、多边形、停顿重瞄、弧线、预警激光和组合符卡。星形与定向米粒弹图集已重新生成。八阶段可玩战役、击毁演出和胜负页面继续使用。电脑视觉预览有 16 个场景，上限可设 64–4096；板端帧率尚未实测。

## 怎么上板

1. 结束 IDE Debug、其他调试窗口和 Programmer。本版图集已更新，**从旧星海版或飞机版升级，都先重新配置现有 v10 或 v11 bit**，然后退出 Programmer。不需要重新编译 bit；旧素材封存不会因重置 CPU 或单独重载 ELF 解除。
2. 双击工程根目录的 `start_lunaria_debug.cmd`。也可用交付目录 `output/lunaria/start_debug.cmd`。
3. 点击“连接 / 读取”。提示“板上程序与所选 ELF 不一致”时，点击“加载并运行 ELF”；加载器先检查硬件和文件，再加载 ELF，并上传背景与图集。
4. 首次共上传 600 个 4 KiB 块、2,457,600 字节。每块等待固件写 DDR 并回读校验；JTAG 上传可能需要数分钟，请等待“背景和图集已完整校验并封存”。
5. 在串口区选择板卡 UART 的 COM 口并开始发送。方向键 / WASD 移动，空格 / Ctrl 射击，P 暂停，Esc 停止电脑端键盘发送。标题页按射击开始，也可点击“星海战役”。

同一套素材已封存且完整哈希匹配时，只需重载 ELF，固件回读校验后复用素材。从星海切回飞机/压力版、更新素材、上传中断后重试，都先重新配置匹配的现有 bit。加载器不自动重置平台、不清硬件错误、不直接向 DDR 写素材。

## 子弹数量与旋转设置

调试窗口“敌弹上限 64–512”可选 64/128/256/384/512，也可输入范围内任意整数，默认 256。此值限制同时存活敌弹（包含边界缓冲区内的敌弹），不是每帧固定显示数量；玩家弹、激光和特效另计。点击“应用”后，在帧边界清除当前敌弹、玩家弹和激光并重启当前弹幕，保留阶段、Boss HP、分数和生命，重置数量峰值。重开保留设置；重载 ELF 恢复默认值。

较小上限降低发射频率；大于 256 时增加每批采样数。完整花瓣和星形始终整批发射，容量不足时延后。勾选“扩张时旋转花瓣 / 星形”可以边扩张边旋转，默认关闭。60 秒测量期间锁定设置。

HDMI HUD：`FPS` 为实际完成呈现的帧率；`B 当前/峰值` 为可见敌弹；`A 当前/峰值` 为敌弹、玩家弹、玩家、Boss、效果和激光；`MAX` 为存活敌弹上限。JTAG 状态读取会短暂停 CPU，窗口数据是最近一次快照；稳定帧率使用“连续测量 60 秒”验收。

## 八种弹幕

| 阶段 | 实现 |
|---|---|
| RING | 环形、自机狙与留隙圆环变体 |
| SPIRAL | 六臂螺旋与正反旋叠加 |
| SUNFLOWER | 黄金角约 137.5°，整数平方根实现减速扩散 |
| ROSE | 3/4/5/6 瓣和 k=7/3 分数玫瑰，可选整组旋转 |
| PENTAGRAM | 五角星轮廓和三至六边形，可选整组旋转 |
| HEXAGRAM | 六芒星与五角星批次交替，可选整组旋转 |
| CURTAIN | 加速幕帘、减速停顿重瞄、独立弧线和激光 |
| FUSION | 诱导弹、星弹、摆动幕帘、花瓣、黄金角和激光叠加 |

每阶段 28 HP，总计 224 HP，由真实射击击败后进入下一阶段，切阶段清弹并预警 500 ms。花瓣和星形保存出生中心，默认只让新批次改变方向；开启旋转时各组围绕出生中心约每秒转 27.5°。256 默认档的 4/5/6 瓣每组 32/40/48 颗，512 档分别 64/80/96 颗。采用查表和定点运算。普通弹主要越界回收，16 秒兜底寿命，取消原来约 3 秒淡出。激光先预警 700 ms，再点亮并判定碰撞，1800 ms 时结束。

三条生命，无敌默认关闭；明确勾选调试选项并应用后才开启，HUD 显示 INV。暂停冻结战斗、预警、特效和结算计时。命中播放约 120 ms 爆炸，绘制在 Boss 上方；最后一击立即停战清弹，约 800 ms 连续爆炸后显示 VICTORY 与分数。胜利页至少停留 3 秒，此后松开并重新按射击才重开，持续按住不会跳过。

## bit、ELF 和素材

- 本次改 RISC-V 软件、渲染命令和素材，复用现有 v10 / v11 图形接口，核心保持 100 MHz。
- 新 ELF：`software/lunaria/build/lunaria.elf`，不覆盖原 `survival_game.elf`。
- `output/lunaria/assets.json`、`background.argb`、`atlas.argb` 与 ELF 必须配套。ELF 不嵌入 2.46 MB 图片；首次仅用 IDE 下载 ELF 会停在等待素材状态，需使用专用加载窗口。
- 实际渲染 640×480；v10 显示 640×480 @(640,300)，v11 显示 1280×960 @(320,60)，HDMI 保持 1920×1080。
- Boss 112×112、敌弹 16×16、玩家/爆炸 32×32。图集采用普通 source-over Alpha，光晕来自纹理，没有新增加色混合硬件。HTML 设计预览的 32px 敌弹在工程图集中缩为 16px。
- 保留 sprite base 0x01384000 / stride 2560、background base 0x02000000 / stride 7680、源窗口 (640,300,640,480)、命令 FIFO 和安全双缓冲。
- 原控制邮箱布局和编号保留。本 ELF 实现命令 1/2/3/4/6/7/10，不支持原飞机自测/48-470 压力场景，专用窗口已隐藏这些入口。
- 本 ELF 的 `g_game_presentation.state`：0 标题、1 入场、2 战斗、3 预警、4 击毁、5 胜利、6 失败。

## 已验证与待验收

本机直接编译实际 C 逻辑和渲染器，检查了八种出生点、旧花瓣/星形的方向和出生中心不变、新批次随发射器转动、4/5/6 个花瓣峰值及批次数量、诱导转速和停止条件、多发命中、弹池/特效池满、暂停、最后一击、击毁后停战、胜利重开边沿、计时回绕。射击碰撞控制器横向追随 Boss，并显式开启无敌，三轮约 50.5 秒通关；这不是对真人操作时长的保证。八种弹幕累计约十分钟模拟运行通过。

实际 `lunaria_render.c` 命令检查源/目标边界、四像素对齐和图集区域，在两种不同脏缓冲上重绘结果一致，含 VICTORY/HUD。工程光栅化效果图和结果在 `output/lunaria/verification/`，不是板卡截图。离线加载器测试覆盖完整 600 块、提交顺序、哈希、窗口越界、超时、中断、封存复用和异常恢复。原调试工具回归也通过。

用户板端验收：三轮完整通关、HDMI 观感、暂停和重开、十分钟连续运行及硬件错误计数，并对八种弹幕分别测量 60 秒。先显式开启无敌并应用，进入所需战斗阶段，再点“连续测量 60 秒”；区间内清除在途玩家子弹，屏蔽射击和暂停，保持当前弹幕阶段。这是动态弹幕测量，原 48 敌机/470 敌弹压力包另行保留。

记录平均/完整秒窗 FPS、绘制耗时、超预算帧、相邻呈现边界和原始重复帧差值。端点差值应与相邻呈现间隔一起解释。新纹理可能不命中 v10 的旧敌弹专用缓存，不能用旧游戏帧率推断新版已达 60 FPS。`board_tested`、`stable_60_fps_measured` 保持 false。

本次扩展检查还覆盖 64、65、128、256、384、512 六档数量，每档运行八种弹幕；不是八档数量。三轮模拟通关均为 50464 ms，默认八种弹幕累计 600064 ms 耐久模拟通过。测试控制器开启无敌，不代表真人通关时长。

`verification/host-checks.json`、`loader-checks.json`、`preview-checks.json` 保存实际结果。打包核对源码、ELF、图集与检查报告的 SHA-256，拒绝混入编译或检查后再改动的文件。具体 OCRAM 用量和 8 KiB 栈空间见 `manifest.json`。

参考视频最高约 3800 颗敌弹，板端最多 512，不能同密度复刻。浏览器有 16 个独立效果场景；板端把变体组合在八个可玩阶段，节奏、采样数和绘制方式不同。`preview.html` 供对照外观，实际板端效果以 C 光栅化图与 HDMI 验收为准。

## 重建和检查

使用 Python 3 与 RISC-V IDE 工具链：

    python scripts/build_lunaria.py --ide-root D:/Efinity/efinity-riscv-ide-2026.1

修改 PNG 后，使用有 Pillow 和系统字体的 Python：

    python scripts/build_lunaria.py --prepare-assets --ide-root D:/Efinity/efinity-riscv-ide-2026.1

离线检查和交付：

    scripts\run_lunaria_checks.cmd
    python scripts/run_lunaria_loader_checks.py
    python scripts/run_game_debug_checks.py
    python scripts/package_lunaria.py

源码为独立实现，取用本工程程序生成的星海素材，没有声称移植第三方游戏。原 PNG、HTML 设计预览、飞机工程、旧 bit 和压力软件均保留。
